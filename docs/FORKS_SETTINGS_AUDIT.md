# Сравнение форков: настройки и интерфейс

Проверено по локальным декомпилированным сборкам exteraGram 20261102, AyuGram и OpexGram 13.1.1-beta10 и исходникам 100gram. Это статический аудит; без проверки на устройстве работоспособность и визуальное совпадение не гарантируются. Наличие названия в старой карте паритета само по себе не считается подтверждением.

| Направление | Находка в форках | Состояние 100gram | Приоритет |
|---|---|---|---|
| Превью сообщений | exteraGram `preferences/chats/components/MessagesPreviewCell` создаёт `MessageObject` и `ChatMessageCell` | Нативные ячейки добавлены в `MessageBubblePreviewCell`; нужна проверка всех переключателей на устройстве | Высокий |
| Превью стикеров/GIF | exteraGram использует ячейки сообщений с тестовым медиа | `StickerSizePreviewCell` использует недавние медиа и `ChatMessageCell`; при отсутствии медиа показывает пояснение | Высокий: проверить GIF, стикеры и пустые списки |
| Удалённые сообщения | AyuGram `CustomizationPreferencesActivity` и `DeletedMessagePreviewCell` показывают пример рядом с настройками | Есть значки, выбор цвета и хук в `ChatMessageCell`; добавлен пример с реальной ячейкой | Высокий: проверить значки и цвета |
| Список чатов | exteraGram `appearance/components/ChatListPreviewCell` содержит пример списка | `md3ChatList` сохраняется, но применение в списке не обнаружено | Высокий: реализовать или явно обозначить незавершённость |
| Нижняя навигация | exteraGram `AppearancePreferencesActivity` имеет отдельный параметр navigation bar в группе MD3 | `md3NavigationStyle` хранится, но не используется вне настроек; `MainTabsActivity` имеет собственный Glass UI | Высокий: спроектировать привязку к текущему контролу |
| Блоки настроек | exteraGram объединяет MD3-параметры в `SwitchGroup`; AyuGram разбивает функции по категориям | `md3Sections` применяется на экранах 100gram, но раздел интерфейса длинный и мастер-переключатель фактически принудительно включает некоторые стили | Средний: разделить экраны и уточнить семантику мастера |
| Контролы MD3 | exteraGram отдельно управляет переключателями, слайдерами, плеером и загрузчиками | `Switch`, `SeekBarView`, `AudioPlayerAlert` содержат отдельные хуки; покрытие нужно проверить отдельно, `md3Controls` не является полным набором кнопок/чипов | Средний |
| Меню сообщений | OpexGram `kc/w1` содержит экран настройки с действием сброса | `HundredGramMessageMenuActivity` и `HundredGramMessageMenu` уже реализованы; необходимо тестировать порядок, скрытие и сброс | Средний |
| Тактильный отклик | OpexGram `kc/o1` содержит отдельный экран | `HundredGramHaptics` и конфигурация действий присутствуют; фактическое покрытие хуков не проверено полностью | Средний |
| Поиск | OpexGram `kc/t2` связывает пункты и переходы | Сверка строк с индексом выявила и исправила 26 устаревших ID; скрытые настройки призрачного режима теперь ведут к управляющему переключателю. Остальные специальные экраны и зависимости требуют отдельной проверки | Высокий |
| Бэкап | OpexGram имеет сброс настроек, в 100gram есть JSON-экспорт | Выявлена потеря типов JSON для long и наборов строк; исправлено в `HundredGramBackupManager`, старые копии остаются поддерживаемыми | Высокий: тестировать импорт на отдельном профиле |
| Фильтры по шаблонам | AyuGram содержит `RegexFilterEditActivity`, экраны списка фильтров и исключений | В 100gram есть `HundredGramContentFilterController`; совместимость правил, импорт и поведение выражений требуется сравнить, наличие аналогичного экрана не доказывает полный паритет | Средний |
| Планирование подарков | В локальном индексе OpexGram указан экран `kc/i3` и обработчики подарков | Поиск по именам scheduled/schedule gift в Java 100gram совпадений не дал; наличие другого механизма не исключено | Кандидат после проверки протокола и пользовательского подтверждения |
| Гибкая конфигурация поиска | exteraGram прикрепляет `linkAlias` к строкам настроек в `AppearancePreferencesActivity` | 100gram использует отдельные числовые ID в поисковом индексе; ручное дублирование создаёт риск устаревших переходов | Высокий: сверить индекс с видимыми строками |
| Режим невидимки/архиватор | AyuGram имеет Ghost, Spy и Filters; 100gram имеет свои экраны и дополнительные политики хранения | Требуется отдельный аудит поведения и пер-аккаунтных данных, переносить вслепую нельзя | Средний |

## Предлагаемый порядок дальнейшей работы

1. Прогнать установленный APK на телефоне: пустые/непустые медиа, смена размеров, ориентация, масштаб шрифта и тёмная/светлая темы.
2. Исправить два неподключённых пункта MD3, не изменяя текущий вид при выключенных опциях; проверить существующий стек навигации и конфликт с Liquid Glass.
3. Разделить большой экран интерфейса на подэкраны с сохранением глубоких ссылок, поиска и существующих ключей.
4. Проверить резервное копирование значений каждого типа и конфигураций, которые хранятся вне `hundredgram_config`.
5. Проверить функциональные различия OpexGram по исходному индексу, не добавляя дубликаты уже существующих функций.
