## Уже присутствует или требует проверки, а не повторного порта

- `disableUnarchiveSwipe` подключён в `DialogsActivity`; `swipeToPip` и управление громкостью имеют конфигурацию и UI — фактические хуки надо проверять по каждой функции.
- Калькулятор уже интегрирован в поле ввода; не заменять его целиком только ради совпадения с exteraGram.
- Обычное изменение скорости аудио уже есть в `AudioPlayerAlert`; это не подтверждает наличие отдельного режима изменения высоты тона.
- В 100gram есть STT, лирика, плейлисты, лента, фильтры и плагины; названия сами по себе не подтверждают полный паритет с реализациями exteraGram.

## Границы аудита

Не все ветки декомпиляции восстановлены полностью; часть методов содержит `UnsupportedOperationException` от декомпилятора. Для каждой реализации нужны отдельные проверка поведения, совместимости лицензий и проектный контракт настройки: хранение, UI, EN/RU, поиск, бэкап и сброс. Внешние сервисы и сетевые запросы должны включаться пользователем явно.
